# Alephant AI

Alephant AI provides an OpenAI-compatible gateway for routing model requests,
attaching session headers, and surfacing request and usage analytics.

The `langchain-alephantai` Python package includes a `ChatAlephantAI` chat
model configured to send requests through Alephant Gateway with Alephant session
headers.

## Installation

```bash
pip install langchain-alephantai
```

## Credentials

Create an Alephant Virtual Key in Alephant Cockpit and use it as the API key.
The production gateway base URL is `https://ai.alephant.io/v1`.

```bash
export ALEPHANT_API_KEY="vk-..."
```

## Chat model

```python
import os

from langchain_alephantai import ChatAlephantAI

llm = ChatAlephantAI(
    api_key=os.environ["ALEPHANT_API_KEY"],
    model="gpt-4o-mini",
    session_name="langchain-chat",
)

response = llm.invoke("Write a one-line product tagline for observability.")
print(response.content)
```

`ChatAlephantAI` accepts additional keyword arguments supported by
`langchain_openai.ChatOpenAI`, such as `temperature`, `timeout`, and
`max_retries`.

```python
llm = ChatAlephantAI(
    api_key=os.environ["ALEPHANT_API_KEY"],
    model="gpt-4o-mini",
    session_name="langchain-chat",
    temperature=0,
    timeout=30,
)
```

## Session headers

Alephant session metadata is attached through gateway request headers. The
package generates an `Alephant-Session-Id` by default and can include an
explicit session name.

```python
from alephantai import AlephantGatewayContext

ctx = AlephantGatewayContext(session_name="customer-support-eval")
```

The current Cockpit API surfaces request and aggregate usage metrics, including
model, provider, status, latency, tokens, and cost. It does not currently expose
session-level query APIs.

## Custom gateway URL

Use `base_url` when testing against a staging gateway.

```python
llm = ChatAlephantAI(
    api_key=os.environ["ALEPHANT_API_KEY"],
    model="gpt-4o-mini",
    session_name="langchain-chat",
    base_url="https://ai.alephant.io/v1",
)
```

## API reference

- PyPI: `langchain-alephantai`
- Import: `from langchain_alephantai import ChatAlephantAI`
- Gateway helper: `alephantai.AlephantGatewayContext`
- Default production base URL: `https://ai.alephant.io/v1`
